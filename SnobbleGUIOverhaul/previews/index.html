Gem Shop previews

Section 1 is real: frames saved from a real Minecraft 1.21.1 client running SnobbleHelper 3.9.1 and the hub on my test server (a throwaway player, 1280x720 window). The shop was opened with the real /hub shop command and the purchase went through the server's quote-then-confirm path (2,500 to 2,250 Gems). Section 2 is a hand-drawn layout mockup for talking about structure, not an accurate render. The game's own advancement toast ("Check out the starters!") and a leftover mouse hover tooltip show up in some frames; they are not part of the shop.
