# Distortion Veil + Umbra Mantle

Status: implemented and running in a private TEST preview. Not deployed to production; final art and performance approval remain separate.

## Player experience

- Broad violet and scarlet ribbons flow around the boundary, with shaded, smoothly filtered alpha textures and drifting embers.
- Soft ground wisps and individual light motes draw broken spiral currents. There is no solid clock disc, metallic crest, or Halloween texture in this path.
- A dark violet/scarlet mantle moves around the shared Giratina's shoulders and wings. The face and central body remain readable.
- Full / Minimal / Off preferences control density. Scene arrival reveals over 1.8 seconds; absent updates fade out by six seconds, even when world time is paused.

This requires the updated optional client companion, currently packaged in `CobbleRaids-Radar-Client-0.4.2+1.21.1.jar`. The private preview has it installed. The core remains compatible with a dedicated server and has no required client-companion dependency.

## Implementation

The new client renderer is independent of the radar display. The server sends bounded scene state every 24 ticks at the existing eight-tick border cadence; animation and motes are generated locally. Full has at most 2,722 quads, Minimal 990, and Off none. These are geometry counts, not measured frame-time approvals. The VFX do not create server particle streams, ticking effect entities, AI, collision, or saved scene entities.

The client uses standard translucent/entity-emissive render layers, depth testing, continuous ribbon joins, and three deterministic alpha textures generated by `tools/distortion_veil_art.py`. All three textures enable linear filtering. No vanilla shader is replaced.

Only the server-supplied entity ID **and** UUID can receive the mantle or expanded client render bounds. Invisible duel copies and other Pokemon retain their normal handling. Scene sequence numbers reject stale updates; each new scene receives a fresh reveal. Disconnects and world/dimension changes clear client state. Shared codec registration is idempotent when the core and companion initialize together.

The initial mantle used an authored **Altered Giratina envelope**. It has now been replaced with animated wing attachments; see [the motion review](UMBRA-MANTLE-MOTION-2026-11-27.md) for current behavior, bounds, artifacts and checks. Its inspected model reaches 101.12371/16 blocks high before boss scale. Native capture proved its client collision box is only 1×1, so collision size is not used to size the effect. Future seasonal species need their own authored profile. Ground wisps currently assume the designated flat arena floor.

The new scene is enabled only for TEST events with `-Dcobbleraids.worldboss.distortionPrototype=true`. It takes priority over the earlier Sovereign prototype. Production defaults are not switched.

## Distance bug fixed

The native near/far regression initially passed around 55 blocks and failed around 95: the shared Giratina was absent from the client even though the server still reported it at [0.5, 65, 0.5]. The ribbons remained visible, exposing the tracking failure.

The fix extends tracking only for the owned showpiece to at least zone radius + 32 blocks, retaining larger native ranges and disabled tracking. Normal view/chunk gates remain in force. The companion also supplies distance and frustum culling appropriate to the enlarged owned model, while leaving its collision unchanged. Pinned bytecode confirmed the concrete PokemonEntity non-passenger distance override delegates to the vanilla superclass implementation and inherits LivingEntity's culling bounds; those verified delegate paths are the client injection targets.

The original regression now passes near, at roughly 95 blocks, and at the 105-block observer position. The portable retained regression was run successfully against the final source/client/server artifacts. It also passes with effects Off. Native reports show `render=true`, collision 1×1, and expanded render bounds [-25.5,62.6,-25.5] to [26.5,91,26.5] for this scaled model.

Run the retained regression with the active disposable rig and native capture probe:

```text
python validation/smoke/worldboss_veil_visibility.py --rig <private-rig> --output <probe-capture-directory>
```
