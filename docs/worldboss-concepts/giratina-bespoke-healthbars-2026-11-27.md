## Implementation boundary

The generated sheet is an art-direction reference. It is not a shipped sprite atlas or proof of 1:1 runtime reproduction. A selected direction still needs an authored pixel grid, adaptive text layout, Full/Minimal/Off treatment, texture/animation budget and native review against the actual Minecraft viewport. Existing event identity, health authority, fallback and other-mod compatibility remain requirements.
